# calculadoraporcentagem.github.io (Hugo)

Rodar local: `hugo server`. Build: `hugo --gc --minify`.

Antes de publicar:
1. Baixe o Inter variável (subset latin, woff2) para `static/fonts/inter-var-latin.woff2`.
2. Revise `content/sobre.md` e `content/privacidade.md`.
3. Para anúncios, preencha `params.adsense` e `params.adslots` em `hugo.toml`.
4. Ative GitHub Pages com a fonte "GitHub Actions" no repositório `calculadoraporcentagem.github.io`.
